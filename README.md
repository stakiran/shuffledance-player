# shuffledance-player
<img width="560" height="826" alt="Image" src="https://github.com/user-attachments/assets/b39d05c6-934e-4545-b913-0e9b4386fb64" />

シャッフルダンスで音ゲーっぽく遊ぶためのツール。

## あそびかた
- index.html にアクセス
- BPM をセット
    - 曲は自分で別途流してね
- 再生ボタンを押して、譜面を開始する
    - また必要なら +-.05 ボタンでタイミングを合わせる
    - スマホで遠目で見るなら「遠目」ボタンで全画面的にするのが良い

## おどりかた
画面を見ながら、横に移動します。1,2,3,4 とあるとおり四分割してください。

## 譜面の読み方
- ノーツ
    - 長さとして1拍、2拍、4拍、8拍がある
    - その長さの間に、ノーツに表示された **向き** を向いて、引かれた線のとおりに移動する
