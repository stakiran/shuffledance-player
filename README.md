# shuffledanceplayer

シャッフルダンスの練習用に、ノーツを流す単独の Web ページ。曲は再生しない。曲は別のプレイヤーで流し、その BPM をこのページに入れて使う。

技名ではなく「どの位置から、どの位置へ、何拍で移動するか」と「体の向き」をノーツにする。どの技でそれを達成するかはプレイヤーに委ねる。

## 使い方

`index.html` をブラウザで開くだけ。ビルドも外部ファイルも不要。GitHub Pages に置くならそのまま公開する。

## 譜面の読み方

- 位置は横一列の 4 レーン。ノーツは下から上へ流れ、上の判定線に頭が来たら開始。
- ○が今いる位置、○から伸びる線の先が移動先。拍数はブロックの長さで読む。
- 体の向きは○に付いた塗りの三角（▲◀▶）。色も向きごとに違う。
- 前のノーツの移動先が次のノーツの開始位置になる。

## 譜面生成のルール

- 1 小節は 8 拍で、ノーツは小節をまたがない。拍数は 2・4 が基本、1 はアクセント、8 は大移動（0 または 3 レーン）。
- 移動距離: 2 拍で 0〜1、4 拍で 0〜2、8 拍で 0 か 3 レーン。
- 移動するノーツの向きは正面か移動先と逆（後ろ向き）の二択で 1:1。移動先と同じ向きは出さない。横向きで留まるのは留まるノーツだけ。留まるノーツは同じ向きが 3 ノーツ続いたら変える。

## 操作

- ページ内のクロックで進む。「開始」で動き出し、曲の小節の頭で「Top」を押すと今を小節の頭に合わせる（止まっていれば開始もする）。
- ずらす操作は「−が戻る、＋が進む」: −.05/＋.05（0.05 秒。反応の遅れの微調整）、−4/＋4（4 拍。止めて譜面を眺めるときや、頭が半小節ずれたとき）。
- キーボード: スペース＝開始/一時停止、Enter＝Top、←→＝0.05 秒戻す/進める。
- 「遠目」で全画面にして譜面だけを大きく出す。離れた所から見るとき用。先は 4/6/8 拍に絞り、ノーツは全部濃く塗って今のノーツは白い太枠にする。画面をタップすると操作（開始/一時停止、Top、表示拍数、戻る）が下に出て、数秒で引っ込む。端末の戻る操作や Esc でも抜けられる。
- BPM は手入力のほか、よく使う値のボタンで一発で入れられる。ボタンの値は html 内の `BPMS` 配列に直書きしてあるので、必要に応じてそこを編集する。
- BPM と表示拍数（通常・遠目それぞれ）は localStorage へ保存する。
